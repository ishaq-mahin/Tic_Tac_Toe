# C Winsock Multiplayer Tic-Tac-Toe

A terminal-based, real-time multiplayer Tic-Tac-Toe game written in C using TCP Sockets (`winsock2.h`).

## How to Play
1. Download the repository to your Windows machine.
2. Navigate to `game_server/bin/Debug/` and double-click `game_server.exe` to start the server.
3. Navigate to `game_client/bin/Debug/` and double-click `game_client.exe` to connect Player 1 (X).
4. Double-click `game_client.exe` a second time to connect Player 2 (O).
5. Enter your moves in the terminal using the format `row col` (e.g., `2 2` for the center square) separated by a space.
